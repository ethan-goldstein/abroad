# ABROAD — A Semester in Motion

A photoreal 3D globe trip-tracker built with Vite, React, and Three.js — 18 weekends across a study-abroad semester based in Florence, each pinned to the map with photos and notes.

## Stops

Tuscany, Rome, Pompeii & Naples, Milan, Switzerland, Paris, London, Bologna, Prague, Amsterdam, Castiglioncello & Pisa, Morocco, Malta, the Amalfi Coast, and more.

## Stack

- Vite + React
- Three.js — the interactive photoreal globe
- GSAP + Lenis — scroll-driven animation and smooth scrolling
